# Bitacora de repositorios clonados

## Cuantos commits tiene el repositorio de mi companera y cual fue el primero
Tiene 1 commit en total, y es el unico que existe: "Initial commit". Apenas contiene el README.md, asi que recien esta empezando el taller.

## Su estructura de carpetas se entiende sin preguntarle nada? Que le cambiaria
No tiene estructura de carpetas todavia: el repositorio solo contiene el archivo README.md en la raiz, sin cuadernos, talleres, proyectos ni documentos. Le sugeriria crear las carpetas cuadernos/, talleres/, proyectos/ y documentos/, igual que pide la guia del taller, para que su material quede organizado por tipo.

## Su README le permitiria usar su proyecto sin ayuda
No. El README solo dice el titulo "Visualizaci-n-de-datos" (el nombre del repositorio, sin acento porque GitHub lo cambia por un guion). No explica de que trata el curso, que contiene el repositorio, ni como esta organizado. Alguien que llegue a ese repositorio no sabria por donde empezar.

## De los tres repositorios, cual esta mejor organizado y por que
git-novice esta mejor organizado, con gran diferencia: tiene un README claro, episodios numerados, y cientos de colaboradores siguiendo la misma estructura durante anos. seaborn-data es simple pero organizado para lo que necesita: son solo datasets sueltos, no requiere mas estructura. El repositorio de mi companera todavia no tiene nada que evaluar, mas alla del README vacio, porque apenas empieza.
